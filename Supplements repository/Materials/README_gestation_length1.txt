FILE: gestation_length1.csv

Description: This csv contains gestation length raw data used for the analysis. Each row represents a species, and each column represents a numerical or categorical variable.

Variables:
species
Scientific species name

taxonomic_order
Taxonomic order of the species

gestation_length
Gestation length (days)

longevity
Maximum longevity (days)

body_mass_g
Average body mass of the species (grams)

female_body_mass_g
Average female body mass of the species

invasiveness
Placenta invasiveness type:
Epitheliochorial
Endotheliochorial
Hemochorial

interdigitation
Placenta interdigitation type:
Villous
