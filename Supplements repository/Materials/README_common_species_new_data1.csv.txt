FILE:common_species_new_data1.csv
Description: This csv contains all common species raw data used for the analysis. Each row represents a species, and each column represents a numerical or categorical variable.

Variables:

taxonomic_order
Taxonomic order of the species

species
Scientific name of the species

gestation_length
Average gestation length of the species (days)

neonate_body_size
Average neonate body size of the species (grams)

interbirth_interval
Average interbirth intervals (days)

litter_size
Average litter size of the species (units)

longevity
Maximum longevity (days)

invasiveness
Placenta invasiveness type:
Epitheliochorial
Endotheliochorial
Hemochorial

interdigitation
Placenta interdigitation type:
Villous
Trabecular
Labyrinthine
