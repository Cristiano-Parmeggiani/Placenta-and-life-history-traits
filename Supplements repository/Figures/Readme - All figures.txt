"Gestation length pgls.png"
Coefficient plots showing PGLS coefficient estimates for placental morphology predictors on gestation length across mammalian species.
Panel a: Placenta types are arranged from the least invasive (epitheliochorial, left) to the most invasive (hemochorial, right), with endotheliochorial in the middle. Colors indicate placenta type. Each point represents the estimated PGLS regression coefficient for that placenta category relative to the reference category, while vertical error bars represent 95% confidence intervals. The reference category is shown at zero, serving as the baseline level in the model comparison.
Panel b: Placenta types are arranged from the least interdigitated (villous, left) to the most interdigitated (labyrinthine, right), with trabecular in the middle. Colors indicate placenta type. Each point represents the estimated PGLS regression coefficient relative to the reference category, and vertical error bars represent 95% confidence intervals. The reference category is shown at zero.
In both panels, the dashed horizontal line at zero represents no difference relative to the reference placenta category. Labels adjacent to each point indicate the estimated coefficient value, standard error, p-value, and Pagel’s λ value associated with the fitted PGLS model. Pagel’s λ indicates the strength of phylogenetic signal in the analysis. Statistically significant p-values (<0.05) are indicated with an asterisk (*)
Positive coefficients indicate higher trait values relative to the reference placenta category, whereas negative coefficients indicate lower trait values.
