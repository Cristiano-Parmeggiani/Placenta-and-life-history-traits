FILE: litter_size.csv
Description: This csv contains litter size raw data used for the analysis. Each row represents a species, and each column represents a numerical or categorical variable.

Variables:
species
Scientific species name

litter_size
Average litter size (number of individual offspring per delivery)

longevity
Maximum longevity in captivity (days)

invasiveness
Placenta invasiveness type:
Epitheliochorial
Endotheliochorial
Hemochorial

interdigitation
Placenta interdigitation type:
Villous
Trabecular
Labyrinthine

taxonomic_order
Taxonomic order of the species
